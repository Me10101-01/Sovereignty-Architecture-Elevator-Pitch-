## Core Principle

Every observation, artifact, experiment, report, command, and invention should be:

- **Attributable** — who, on which device, with which identity
- **Replayable** — the full sequence can be reconstructed
- **Measurable** — ERU, contribution %, power level, provenance depth
- **Verifiable** — GPG-signed, hash-chained, Prometheus-witnessed
- **Evolvable** — each cycle produces a smarter next iteration

## The Distinction That Matters

Most AI projects mean:

```
Agent
  → do task
```

The Council means:

```
Mind
  → discover
  → remember
  → contribute
  → evolve
```

The difference is **specialization, memory, and governance** rather than just automation.

A task agent disappears when the task ends.
A council mind accumulates — every discovery becomes a brain node,
every experiment becomes a ledger entry, every failure becomes a lesson
that the next mind inherits through the corpus callosum.
