# ARIN Org ID Creation Checklist

An Org ID is your organization's handle in the ARIN database.
It is required before you can request an ASN.

---

## Required Information

- [ ] **Legal entity name**: Strategickhaos DAO LLC
- [ ] **Address** (must match state registration):
      Wyoming registered address or your principal place of business
- [ ] **Admin Point of Contact (POC)**: your name, email, phone
- [ ] **Technical POC**: same or different contact for network issues
- [ ] **EIN**: 39-2900295 (for ARIN's records — not always required but have it ready)

---

## Steps

1. Log in to ARIN Online: https://account.arin.net/
2. Dashboard → Organizations → Create New Organization
3. Enter legal name exactly as: **Strategickhaos DAO LLC**
4. Enter address (must be a real, deliverable US address)
5. Create Admin POC (your contact info)
6. Submit — Org ID assigned immediately (no review required)
7. **Record your Org ID** (looks like: `STKH-ARIN` or assigned handle)

---

## After Org ID is Created

Immediately proceed to ASN application (asn-application.md).
Your Org ID is the anchor for all future IP/ASN resources.
